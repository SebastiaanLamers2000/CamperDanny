# Camper Danny

Logboek-app voor de camper: reizen, kaart, agenda, to-do, spots en huuraanvragen.

- `public/` is de app (statische bestanden). Cloudflare publiceert deze map bij elke wijziging op `main`.
- `wrangler.jsonc` zegt aan Cloudflare welke map online moet.
- `supabase/` bevat de SQL-bestanden ter referentie. De database staat al in Supabase.
